Higher entropy indicates stronger passwords.

---

### 4.2 Wordlist Attack Simulation

- Uses a predefined list of commonly used passwords  
- Attempts to match the target password  
- Demonstrates how weak passwords are quickly cracked  

---

### 4.3 Brute Force Attack Simulation

- Generates all possible combinations of characters  
- Attempts passwords up to a defined length  
- Tracks time taken to crack the password

## 5. 🖥️ Methodology

1. User inputs a password  
2. Password is analyzed for strength and entropy  
3. System checks against common password database  
4. Wordlist attack is performed  
5. If unsuccessful, brute-force attack is executed

## 6. 📊 Results & Observations

### 🔹 Weak Passwords
- Cracked instantly using wordlist attack  
- Example: `admin123`, `password`

### 🔹 Medium Passwords
- Require more attempts  
- Vulnerable to brute-force  

### 🔹 Strong Passwords
- High entropy  
- Resistant to both attacks (within practical limits)

## 7. 🔍 Analysis

- Passwords with predictable patterns are insecure  
- Use of mixed character sets significantly improves strength  
- Length plays a critical role in increasing entropy  
- Wordlist attacks are faster than brute-force
