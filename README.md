# 🔐 Password Security & Attack Simulation

## 📌 Overview
This project demonstrates password security concepts including:
- Password strength analysis
- Entropy calculation
- Wordlist attack simulation
- Brute-force attack simulation

---

## 🚀 Features
✔ Password strength checker  
✔ Entropy-based analysis  
✔ Detection of common passwords  
✔ Wordlist attack simulation  
✔ Brute-force attack (controlled environment)
